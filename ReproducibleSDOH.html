ReproducibleSDOH

The umbrella package for the ReproducibleX family. A SLURM pipeline on Stanford Sherlock pre-computes every index × geography × scope × year and publishes them as Parquet releases of ReproducibleSDOH-data. Users then call getYost(), getNDI(), getICE(), getSDI() or getCDI() to get an index in seconds, with no Census API key.

For maintainers · runs on Sherlock

Build a Release

pipeline/

~430 tasks · index × geo × scope × year

Each task is one SLURM array job that writes one Parquet file. Census downloads are cached on disk for the run, so tasks with the same request share one download. Every file records the package and pipeline git commits that produced it.

1

Configure

config.R · registry.R

Run ID, years and pinned package versions. One registry entry per index says what to call and what to write

2

Make Task Grid

make_grid.R

One row per task, split into memory tiers (16 / 48 / 128 GB). National tasks run before state tasks so they share downloads

3

Geography

build_geometry.R

One download per geo × year writes geoinfo (GEOID, NAME, tot_pop) and geometry. Runs first

4

Compute Indices

run_task.R

Calls the sibling compute*() for raw and best. Writes GEOID + scores only, after checking groups, population and NAs in memory

SLURM array jobs, submitted with submit.sh
5

Quality Check

qa_release.R

Every file present, GEOIDs match geoinfo, value ranges, check summaries, and differences from the previous release

6

Publish

publish.R

sha256 checksums and a GitHub release per index, then manifest.json updated. Copied to Box with archive.sh

  • geoinfo and geometry are published first. Every index release names the geoinfo and geometry releases it matches.
  • Re-running a task that already finished does nothing. check_status.R lists failed or missing tasks and prints the command to re-submit them.
  • The pipeline swaps in a caching tidycensus::get_acs() during the run only. None of the sibling packages are changed.

Get an Index

getYost() · getNDI() · getICE() · getSDI() · getCDI()

No Census API key · cached locally

Files are verified by checksum and downloaded once. By default release = "latest"; pin a tag such as release = "ndi-v2026.10" so a paper's numbers never change.

1

Resolve Release

sdoh_manifest()

Reads manifest.json to turn "latest" into a real tag, along with the matching geoinfo and geometry releases

2

Download & Cache

download.R

Downloads the one Parquet file needed, checks its sha256, and saves it to the local cache

3

Read + Join Geoinfo

info = TRUE

Reads GEOID + scores, adds year, geo and scope, and joins NAME and tot_pop from geoinfo

Optional
4

Add Groups

groups = 5

Quintiles, quartiles or percentiles, computed before filtering states so national groups stay national

5

Filter States

states = c(...)

Keeps rows whose GEOID starts with a requested state FIPS code

Optional
6

Attach Geometry

geometry = TRUE

Joins boundaries from the geometry release and returns an sf object

Inside every get*() call, in the shared engine sdoh_get()
getYost()Yost Index (raw, stabilized + imputed)

addQuintiles()also addQuartiles(), addPercentiles(), addGroups()
addIndexGroups()each index's original grouping
sdoh_export_csv()Parquet → CSV, GEOID kept as text
sdoh_open()arrow query across cached files
sdoh_releases()list published releases
computeSDOH()compute locally with the sibling package
  • Options that aren't pre-computed, such as scope = "county", go through computeSDOH(). It calls computeYostIndex(), computeNDI(), computeICE(), computeSDI() or computeCDI() from the sibling package, which is installed only when needed.
  • Files store scores only. Groups are always computed from the scores, so they can never disagree with them.
