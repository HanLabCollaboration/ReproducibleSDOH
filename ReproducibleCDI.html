ReproducibleCDI

The Community Deprivation Index follows the Singh / Area Deprivation Index method and adds % uninsured, for 18 ACS variables in total. It is built natively at block group, and higher scores mean more deprivation. computeCDI() builds it from the Census API.

Robst et al. 2024

Community Deprivation Index

computeCDI()

Scope: national | state · Years: 2016+

Imputation, standardization, PCA and ranking run separately within each scope group. "state" scope takes effect only when more than one state is requested. The household-internet table (B28002) isn't published before 2016.

Fetch ACS Data

fetchCDIAcs()

18 variables from detailed B/C tables only, so block group works. Includes B27010 (insurance) and B28002 (internet). Names split by cleanAcsNamesCDI()

Compute 18 Variables

calculateCDIVars()

Definitions follow the CMS SAS reference. Zero denominator → 0. Census jam codes on medians → NA

Optional
3

Impute

imputeMissing()

Spatial mean over Queen-contiguity neighbors, weighted by tot_pop (default) or unweighted

4

Standardize

scale()

Complete cases only. All 18 variables z-scored (mean 0, SD 1) within the scope group

5

PCA Weights

psych::principal()

1 component. Its loadings are the weights W, and the composite is S = Z · W. Sign flipped so fam_bel_pov loads positive

6

Rescale & Rank

processCDIScope()

CDI_std rescaled to mean 100, SD 20. our_CDI = percentile 1–100

  • Missing values are filled by spatial queen-neighbor imputation, not the CMS hierarchy (block group → tract → county → state).
  • There is no MOE-based empirical Bayes shrinkage and no low-population or group-quarters suppression. This is the "standardized index without shrinkage".
  • CMS uses factor-score coefficients and this package uses loadings. With 1 component they are proportional, so the ranks after rescaling are the same.
